# Deterministic Five-Language SDK Generation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax.

**Goal:** Deliver a functional, deterministic CCR retrieval SDK-generation pilot for Python, TypeScript, Go, Rust, and .NET, ready for a draft pull request.

**Architecture:** Import-free Python AST harvesting produces one canonical OpenAPI 3.1.1 contract. Five local emitters generate models and endpoint bindings around reviewed per-language HTTP runtime templates. One ownership manifest, drift command, shared loopback server, and additive CI workflow enforce deterministic and behavioral parity.

**Tech Stack:** Python 3.10+ standard-library generator; OpenAPI 3.1.1; TypeScript/Node; Go; Rust with Serde, Reqwest, and Tokio; .NET 10 with System.Text.Json and HttpClient; GitHub Actions.

**Spec:** docs/superpowers/specs/2026-10-01-deterministic-sdk-generation-design.md

## Global Constraints

- Generate only POST /v1/retrieve and GET /v1/retrieve/{hash_key}.
- Keep output experimental under sdk/generated-pilot; do not replace or publish existing SDKs.
- Do not change handler bodies, guards, existing route decorators, return annotations, or FastAPI response behavior.
- Generation must not import Headroom, start the proxy, read credentials, use providers, or download tools.
- Unsupported contracts fail closed; never weaken a type to Any, object, or dynamic.
- Preserve wire names, presence/nullability, false, zero, omission, and unknown response fields.
- Clients use finite timeouts, no retries, no redirects, and bounded response reads.
- Generated bytes exclude paths, line numbers, timestamps, environment values, temporary directories, and Git SHAs.
- Commit each independently verified task and update the progress log with exact evidence.

## Review Focus

- Required-nullable tool_name must reject omission and accept JSON null in all five languages.
- Prefix base URLs and hash keys containing slash, Unicode, spaces, question marks, hashes, and apostrophes must round-trip safely.
- Redirect, oversized body, non-JSON success, timeout, and cancellation must not retry or leak resources.
- Unowned, stale, missing, changed, traversing, and symlinked output must fail without touching unrelated files.
- Working directory, hash seed, timezone, comments, and irrelevant declaration order must not alter generated bytes.
